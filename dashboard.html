            How rules work

            Before an agent or sub-agent uses a tool, its call is checked against these rules from top to bottom. The first enabled match decides: Ask me first pauses the agent and sends a request to Permission requests, Always block stops it, and Always allow lets it through without a prompt. If nothing matches, the agent behaves as usual. Rules are enforced by the bridge, so it must be running.

            Productive

            You typed, clicked, scrolled or moved the mouse within the idle cutoff (10 s by default).

            Waiting on AI

            You're on an AI chat site, you sent a prompt or a reply is still being written, and you aren't typing. Moving the mouse doesn't count as working while you wait.

            Idle

            No input for longer than the idle cutoff on any other site.

            The statistics

            Unproductive
            Waiting on AI plus Idle. Idle can be left out in Settings.
            Productivity score
            Productive time ÷ (Productive + Unproductive).
            AI waits
            Each unbroken stretch of waiting on an AI counts as one wait. It ends when you type, switch tabs or leave Chrome.
            Average / longest wait
            Average and maximum length of those waits.
            Tab switches
            How many times you switched tabs or came back to a Chrome window. This is a rough measure of how often you changed context.
            Timeline
            Each colored block is one continuous stretch of the same state on the same site.
            Permission requests
            Things an agent wanted to do that one of your rules covers. The agent waits until someone with permission approves or denies it, or until the time limit passes.
            Agent inbox
            Every task a main agent hands to a sub-agent, grouped under the prompt you gave the main agent. To review = finished but not yet marked done; Changes = you sent a change request; Done = you marked it done.

            What counts, and how your data is kept separate

            • Only the tab you're looking at counts: the visible, focused tab in the focused Chrome window, while your computer is unlocked. Background tabs never add time.
            • Data is stored only on this computer, in this Chrome profile (chrome.storage.local). It is never synced or uploaded.
            • Each user account has its own separate history. Time is recorded only for whoever is signed in, and nothing is recorded while nobody is. Members see only their own stats; admins can view everyone's.
            • Passwords are stored only as salted PBKDF2 hashes.
            • Incognito windows aren't tracked at all.
            • Each day is stored as its own record. Time that crosses an hour or midnight is split, so it never lands in the wrong hour or day.
            • Only site names (for example claude.ai) are stored. Page contents, what you type and full URLs are never recorded.
